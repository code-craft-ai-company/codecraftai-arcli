Packaging Conventions
=====================
All Code Craft AI python packages use a root namespace of 'ccai'.  Under the root namespace, the package will
be in a package folder, for example the 'codecraftai-errors' package which provides a shared package for error types and
error handling and formatting functions places all code under the package 'ccai.errors'.


Directory Structure
===================

The project workspace contains a 'source' folder which contains all the code that is part of the the product being built.
